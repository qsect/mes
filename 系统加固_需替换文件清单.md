## G. 部署步骤

```bash
# 1) 备份
cd /www/wwwroot/vite && tar -czf /tmp/backup_$(date +%s).tar.gz backend frontend/src

# 2) 上传 A/B/C/D/E 列表文件（勿含 legacy_trace.php）

# 3) 服务器手工改 legacy_trace.php 开头 5 行（见提醒 1）

# 4) 删除残留文件（见 F）

# 5) 重启 PHP（OPcache 必做）
systemctl restart php-fpm-82

# 6) 前端重建（含 v-safe-html 指令）
cd /www/wwwroot/vite/frontend && rm -rf dist/assets && npm run build

# 7) 浏览器强刷 Ctrl/Cmd+Shift+R
```

> 数据库 `login_attempts` 表由 `Schema::ensureLoginAttemptsTable()` 幂等自愈，**无需手工建表**。
